# Same-Model Subagents Profile Policy Implementation Plan

> **For AI workers:** Required subskill: use `superpowers:executing-plans` to
> execute this plan inline. If the user explicitly authorizes subagent-driven
> execution instead, every child must inherit the current model identity; do
> not select a model override. Track every step with the checkboxes below.

**Goal:** Create the mandatory `same-model-subagents` Skill, retain all existing
Library artifacts, remove explicit orchestration Skills from the two coding
Profiles, and add the new Skill to all eight ordinary Skill Profiles without
Preflight or Apply.

**Architecture:** Keep the policy artifact in the repository under
`.agents/skills`, import it through the existing Browser API, and update
Profiles through `PUT /api/v1/profiles/{id}`. A small Go migration command uses
ToolHub's existing canonical Skill scanner, preserves every existing pinned
Skill/MCP version, performs optimistic revision checks, and supports dry-run,
apply, and verification modes. PostgreSQL is used only for read-only rollout
auditing.

**Technical stack:** Agent Skills (`SKILL.md`, Python 3), Go 1.22,
`net/http`, ToolHub Browser API, PostgreSQL 16, Docker Compose.

```text
Core principle: the child model identity must exactly equal the current parent

6. A request for another child model conflicts with this Profile policy. Stop
   and require an explicit policy/Profile change rather than silently switching.
```
